React Components:
  🔹 Explainability.tsx
     Main page that ties everything together
     Shows search input, transaction details, SHAP plot, LIME table

     Transaction search input form

     - Queries database
     - Runs SHAP explainer (generates PNG)
     - Runs LIME explainer (generates HTML)
     - Returns explanations to frontend
